# Fake Product Review Detection & Trust Scoring System

This is a full-stack e-commerce marketplace application for detecting fake product reviews and calculating trust scores.

## Project Overview

- **Backend**: Node.js/Express API with MongoDB
- **Frontend**: React with modern UI components
- **Features**: Review analysis, trust scoring, product image uploads, fake review detection

## Setup Instructions

1. Install dependencies: `npm install` (in both backend and frontend folders)
2. Configure environment variables (.env files)
3. Start MongoDB locally or configure remote connection
4. Run backend: `npm start` in backend folder
5. Run frontend: `npm start` in frontend folder

## Tech Stack

- Express.js for REST API
- MongoDB for data persistence
- React for frontend UI
- Multer for image uploads
- Natural for NLP-based review analysis
